# Материалы к расширенному разбору управления

Документ: [docs/control_review.md](../../docs/control_review.md).

Обзор источников: [docs/industry_field_weakening.md](../../docs/industry_field_weakening.md).

Подробный разбор наружного ОП: [docs/field_weakening_loop.md](../../docs/field_weakening_loop.md).

Эти инструменты воспроизводят исследование **исходной** модели. Предлагаемый в документе
регулятор здесь не реализован. Модель и инструменты предыдущего исследования не изменяются.

- run_review.m запускает четыре сценария на копиях SLX через существующий run_aug.
- figures.py строит семь PNG, включая две схемы Graphviz, и сохраняет DOT-исходники схем.
- docs/data/control_review/ содержит выдержки из логов и полную численную сводку.
- industry_figures.py строит шесть оригинальных иллюстраций обзора, включая три
  схемы Graphviz. Источники и происхождение изображений указаны в обзоре.
- model_figures.py строит шесть схем текущей модели М1–М6 и извлекает карту
  используемых блоков с SID и параметрами. Перед построением проверяет SHA-256 SLX.
- fw_loop_figures.py строит восемь иллюстраций подробного разбора ОП, три DOT
  и docs/data/fw_loop_analysis.json. Проверяет SHA-256 SLX; использует уравнения
  машины и явно заданные приближения, без замкнутого прогона FOC.

Команды выполняются из корня репозитория.

```matlab
addpath tools/control_review
run_review  % полные MAT и копии SLX: work/control_review
```

Требования MATLAB и библиотек — в [исходном README](../fw_limiter/README.md).

```bash
# Перерисовать по уже сохранённым CSV, без MATLAB:
python3 tools/control_review/figures.py

# Перестроить иллюстрации промышленного обзора:
python3 tools/control_review/industry_figures.py

# Перестроить схемы текущей модели и карту блоков (Python + Graphviz):
python3 tools/control_review/model_figures.py

# Пересчитать иллюстрации динамики и схемы наружного ОП:
python3 tools/control_review/fw_loop_figures.py

# Заново извлечь данные из полных прогонов и перерисовать:
python3 tools/control_review/figures.py --runs work/control_review
```

Для графиков нужны NumPy и Matplotlib; для чтения MAT нужен SciPy; для схем —
установленный Graphviz с командой dot. При недоступном домашнем каталоге конфигурации
Matplotlib можно задать MPLCONFIGDIR=/tmp/adaptto-mpl перед командой.

Режим --runs ожидает все четыре MAT и соответствующие копии SLX. Контрольная сумма
модели берётся из копий этих прогонов. Номинальные параметры для расчётных кривых заданы
в P внутри figures.py и соответствуют исследованной версии модели; при изменении
параметров их нужно актуализировать вместе с текстом документа.

Максимумы в summary.json вычисляются по полным логам с линейной интерполяцией
на сетку Id/Idreq для сопоставимости с дополнительной проверкой. CSV ограничены
временными окнами графиков; дискретные команды в них интерполируются удержанием.
Они не заменяют полные логи и не предназначены для строгой приёмки исправленного регулятора.

Воспроизведение графиков по CSV проверено. Новый MATLAB-скрипт содержит те же четыре
вызова run_aug, которые уже выполнены при исследовании; отдельный повтор всех
прогонов только ради упаковки материалов не проводился.

При пересмотре 09.11.2026 обновлены текст, схема предлагаемой структуры и геометрия
сравниваемых ограничителей. MATLAB-модели, CSV и численная сводка прежних прогонов
сохранены. Рисунок начальной реакции на уменьшение напряжения вычисляет только
производные в момент t = 0+; он не является испытанием замкнутого FOC.

Схемы М1–М6 в разделах 2–3 описывают текущие соединения модели. Это функциональные
реконструкции, сгруппированные для чтения; они не являются автоматической раскладкой
всего листа Simulink. Карта `docs/data/control_model_structure.json` связывает схемы
с блоками. При изменении SLX нужно сверить связи и обновить описание до изменения
ожидаемой контрольной суммы в model_figures.py.

Дополнение 10.11.2026 описывает действующий FF/trim/sens, наружные законы VESC,
IR/Infineon, TI и опубликованные функции серийных приводов. Отдельно рассчитаны
статическая чувствительность, обратная начальная реакция и условный частотный канал.
Это новые аналитические материалы; прежние MAT/CSV, сводки прогонов и SLX сохранены.
Источники закреплены в docs/data/fw_loop_sources.json, происхождение восьми новых
изображений — в docs/img/fw_loop/README.md.
