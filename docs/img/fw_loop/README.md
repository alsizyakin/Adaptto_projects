# Иллюстрации подробного разбора контура ОП

Все изображения созданы [fw_loop_figures.py](../../../tools/control_review/fw_loop_figures.py)
для [field_weakening_loop.md](../../field_weakening_loop.md). Производитель не является
автором этих изображений; это собственные расчёты и функциональные реконструкции.

| Файл | Основание и предел вывода |
|---|---|
| 01_static_budget.png | Установившиеся напряжения машины с параметрами Adaptto; сечения включают недостижимые точки |
| 02_inverse_response.png | Напряжение для заданной извне траектории Id; замкнутые регуляторы не моделируются |
| 03_sensitivity.png | Статические gd и нормировка sens; положительный нуль локальной модели при фиксированном Iq |
| 04_vesc_fw.png | Упрощённые связи по коду VESC закреплённого коммита; не все режимы прошивки |
| 05_vendor_loops.png | Опубликованные структуры/функции IR AN-1090, TI TIDM-02017 и Cascadia; скрытая логика не дорисована |
| 06_candidate_structure.png | Предлагаемая архитектура Adaptto, вариант C; в SLX не реализована |
| 07_current_paths.png | Статическое сравнение изменения одного Id и движения по постоянному Is |
| 08_local_frequency.png | Расчёт P(s)/gd при условном Ti(s) = 6000/(s + 6000); не идентификация SLX |

DOT-исходники трёх схем сохранены рядом. Рисунок текущего ОП из
`../control_review/10_field_weakening.png` используется повторно и создаётся model_figures.py.
Числа сохранены в [fw_loop_analysis.json](../../data/fw_loop_analysis.json), источники —
в [манифесте](../../data/fw_loop_sources.json).

Расчёты используют постоянные параметры и электрическую скорость 5000 рад/с.
Вывод о положительном нуле ограничен указанной локальной моделью и не объявлен
доказанной причиной прежних колебаний либо защёлкивания полного привода.
