# Иллюстрации ревью управления

PNG вставлены в [control_review.md](../../control_review.md) по относительным путям.
Все схемы созданы для документа; графики исходных прогонов используют сохранённые
CSV из `docs/data/control_review`.

Файлы 01–07 строит [figures.py](../../../tools/control_review/figures.py).
01 показывает общую действующую структуру, 02–04 — данные исходной модели,
05 — расчёт SVPWM, 06 — предлагаемую структуру, 07 — геометрию ограничителей.

Файлы 08–13 строит [model_figures.py](../../../tools/control_review/model_figures.py).
Они описывают **текущую** модель `ideal_source_drive_Idff_aug_param.slx`:

| Схема | Файл | Содержание |
|---|---|---|
| М1 | 08_model_plant.png | Объект, независимые воздействия по скорости и Iq, активные измерения |
| М2 | 09_current_loops.png | Два токовых контура, развязка, приоритет d и зависимый предел q |
| М3 | 10_field_weakening.png | FF, обратная связь напряжения, интегратор ОП и разрешение интегрирования |
| М4 | 11_current_references.png | Разные пути Idreq и формирование предела Iq |
| М5 | 12_parameter_feedback.png | Оценки Ψ/Lq и их возврат в управление |
| М6 | 13_voltage_path.png | Угловое опережение, SVPWM, задержка и напряжения источников |

Это функциональные схемы по блокам и соединениям SLX: служебные преобразования,
Goto/From и диагностические ветви объединены. Сплошные стрелки обозначают основной
тракт, пунктир — замыкающие обратные связи, точечные линии — поясняющие зависимости.
На М1 двусторонняя стрелка обозначает физическое соединение вала. Светло-жёлтым
выделены ограничения или условия, которые особенно существенны для чтения ревью;
цвет сам по себе не означает дефект.

Рядом сохранены DOT-исходники. [Карта блоков](../../data/control_model_structure.json)
содержит SID, параметры и SHA-256 модели. Скрипт отказывается перерисовывать схемы
для другого SLX без пересмотра описания. Новых симуляций эти изображения не содержат.
