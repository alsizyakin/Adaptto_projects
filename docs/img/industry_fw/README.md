# Происхождение иллюстраций

Все PNG в этой папке — собственные поясняющие иллюстрации, построенные
[industry_figures.py](../../../tools/control_review/industry_figures.py).
Они не являются изображениями, предоставленными производителями.
Ссылки S1–S9 определены в [обзоре](../../industry_field_weakening.md).

| Файл | Основание | Ограничение интерпретации |
|---|---|---|
| 01_control_layers.png | Обобщение S1–S4, S6–S7 | Не структура одного конкретного изделия |
| 02_vesc_control.png | S1, коммит 3ebf8d1fe8cc485ad588e4272a761785c9cf0c5d | Упрощённая функциональная схема; не все режимы прошивки |
| 03_voltage_limiters.png | Расчёт трёх математических правил ограничения | Условные векторы; не прогоны |
| 04_cascadia_modes.png | S2, §6.2, 0A-0163-04 | Три опубликованных воздействия; внутренние регуляторы не реконструированы |
| 05_current_angle.png | Геометрическое пояснение подхода S6 | Собственная нормировка угла и условные значения |
| 06_radial_initial.png | Уравнения PMSM и номинальные параметры Adaptto | Только начальные производные при фиксированных токах; не динамика FOC |

DOT-исходники трёх блок-схем находятся рядом с PNG. Надписи, цвета и компоновка
созданы для обзора. Копии страниц руководств и логотипы производителей не используются.
