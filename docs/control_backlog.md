При закрытии пункта добавляем дату и ссылку на проверку. Порядок ниже — ориентир выполнения.

## Выполнено

- [x] Ввести `mMaxPWM = 0.99`, `mMaxCurrent = 0.99`, `mFW = 0.95`; согласовать бюджеты d/q и предел SVPWM со скважностями 0,005…0,995.
- [x] Подключить `mMaxPWM` в SVPWM1 как `Parameter`. Работоспособность после исправления подтверждена пользователем 10.11.2026.

## Подготовка и токовые ограничения

- [ ] Сохранить рабочую версию модели и полный контрольный прогон после изменения модуляции.
- [ ] Дополнить логирование: задания и токи d/q, напряжения до/после ограничения, конечные duty, интеграторы, FF/trim, sens, freeze/reset.
- [ ] Исправить метрику потери слежения на модуль ошибки; добавить проверки тока, конечности сигналов и завершения восстановления.
- [ ] Формировать итоговую пару Id/Iq в одном такте внутри токового круга; исключить отставание бюджета Iq из-за фильтра Id.
- [ ] Ввести независимый предел Id по полному току и допустимому размагничиванию машины.
- [ ] Ограничить обе полярности Iq; исключить отрицательный модуль IqLim после smoothmin.

## Напряжение и контуры управления

- [ ] Подготовить контрольную ветвь с фиксированными параметрами регулятора для сравнения без адаптации.
- [ ] Восстанавливать реализованное напряжение по конечным duty и Vdc; согласовать задержки и использование Vdc/Vdc_filt.
- [ ] Сравнить и выбрать ограничитель напряжения: исходный приоритет d, ограниченная доля d, радиальная проекция.
- [ ] Согласовать anti-windup обоих токовых PI с выбранным ограничителем и развязкой.
- [ ] Ввести совместный расчёт достижимой пары Id/Iq с учётом напряжения, тока, Idmin и выбранного ограничения d.
- [ ] Ограничить темп изменения итоговой пары, включая быстрые изменения FF и снятие отрицательного Id.
- [ ] Измерить динамику канала Idref → Us; по результатам выбрать закон ОП, сигнал обратной связи и настройку sens/усиления.
- [ ] Согласовать интегратор ОП с окончательным Idref; пересмотреть freeze/reset и плавность входа/выхода из ОП.
- [ ] Добавить valid/hold, гистерезис и плавное обновление оценщиков при малом возбуждении и быстрых переходах.
- [ ] Устранить смешение ошибки Ld с оценкой Ψ; определить допустимые режимы адаптации потока.

- [ ] Проверить выбранное решение с ключевым инвертором, механической нагрузкой и динамическим DC-звеном.
